This project is a web story (cerita web) developed using HTML, CSS, and JavaScript. The core HTML structure presents the narrative content. I've implemented CSS to enhance the visual appeal and make the website more interesting and engaging for readers. JavaScript is used specifically to manage the navigation bar, allowing it to open and close.
